# Estimators

**Two types of estimators:** 

1. *A point estimate (or maximum likelihood estimator)* of a parameter is a single numerical value of a respective estimator. 
2. *An interval estimate* of a parameter is an interval in which we estimate that the parameter lies. 
	→ The width of the interval depends on how much confidence we can attach to the interval estimate
