# Expectation or Expected Value

***The expected value, or expectation, of a discrete random variable X is given by***
![[Pasted image 20261001110219.png]]

> The formula gives a weighted average of values of a random variable, with the probabilities being the weights of the respective values. The value μ is termed the mean of X.

EXAMPLE:
Find E[X] where X is the outcome when we roll a fair die.

Since p(1) = p(2) = p(3) = p(4) = p(5) = p(6) = 1/6, we obtain that 
	E[X] = 1(1/6)+2(1/6)+3(1/6)+4(1/6)+5(1/6)+6(1/6) = 7/2 = 3.5

> note since die each side has equal chance that's why each number times 1/6 and the expected value does not always have to be in solution set.
